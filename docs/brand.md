# Brand

## Names

- **UwU names:** "UwU" plus the product, one word, product capitalised:
  UwUMail, UwUMirror, UwUNotes, UwULock, UwUSSH, UwURDP, UwUAuth, UwUSync,
  UwUKeygen. The family is the **UwUSuite**.
- **Servers:** "UwUMail Server", "UwULock Server".
- **Never:** "Uwu Mail", "UWUMAIL" or "uwumail" in text. Lowercase is fine for
  ids, file names and bundle ids (`app.uwumirror.desktop`).
- **The cat:** her name is **Nyu**.

## Wordmark

`<Wordmark product="Mirror" shell="mirror" />`

- **Order:** Nyu (the app's shell, 1.35 em high, no blink), an 8 px gap, then
  "**UwU**" in `pink-solid` and the product in `ink`.
- **Weight:** 800 (the only place it is used), tracking -0.02em.
- **Sizes:** 14 px in the title bar, 19 px in a sidebar, 22–36 px on pages.
- **Hop:** `hop={n}` makes Nyu hop once when `n` changes (new mail).
- **Mascot off:** without the mascot (admin setting), the wordmark is text
  only, or the app's line icon in `text-pink`.

## Using it

- **Website, GitHub, store pages:** the app icon (tile) and a screenshot.
- **README:** the app icon at 96–128 px, centred, with the name and one line
  ("Mail, but cute." / "Handy an, Spiegeln tippen, fertig.").
- **Link preview:** Nyu on the tile gradient, 1200 × 630.
- **Placeholders in docs and tests:**
  - Only reserved names: `example.com`, `example.net`, `example.org`,
    `*.example`, `*.test`, `*.invalid`, `*.localhost`.
  - Only documentation IP ranges: `192.0.2.0/24`, `198.51.100.0/24`,
    `203.0.113.0/24` and `2001:db8::/32`.
